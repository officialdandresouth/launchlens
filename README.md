# LaunchLens

**[→ Live Site](https://launchlens-4d46.onrender.com)**

> "You have $10K. This tool tells you where to put it."

AI-powered Amazon FBA product research tool for first-time sellers. Enter your budget — get ranked product categories, deep-dive analysis, unit economics, supplier links, and a date-anchored launch plan.

---

## What It Does

1. **Budget Input** — Set your starting capital
2. **Category Rankings** — 76 subcategories scored on margin, demand, and competition
3. **Category Deep Dive** — Feature satisfaction bars, opportunities, top products
4. **Product Spec Brief** — Claude Sonnet generates a manufacturer-ready spec
5. **Unit Economics** — COGS, FBA fees, margins, and ROI calculator
6. **Supplier Links** — Alibaba search links generated by Claude Haiku
7. **Launch Plan** — Date-anchored 90-day timeline

## Tech Stack

- **Backend:** FastAPI + Uvicorn (Python)
- **Frontend:** Vanilla HTML/CSS/JS, Three.js (3D background)
- **AI:** Claude Sonnet + Haiku (Anthropic API)
- **Data:** ~6,900 Amazon products across 76 categories (pre-scraped via ScraperAPI)
- **Deploy:** Render.com

## Run Locally

```bash
pip install -r requirements.txt
cp .env.example .env   # add ANTHROPIC_API_KEY and SCRAPER_API_KEY
py -m uvicorn backend.main:app --reload --port 8000
```
